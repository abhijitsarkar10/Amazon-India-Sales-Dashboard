# Amazon India Sales Dashboard

## Project Overview
This project analyses Amazon India sales data using Python to understand sales performance, profitability, product categories, order status, payment methods, fulfilment methods, and geographic performance.

## Objectives
- Analyse overall sales and profit.
- Calculate key performance indicators (KPIs).
- Identify top-performing product categories and products.
- Analyse returned and cancelled orders.
- Compare payment and fulfilment methods.
- Evaluate state-wise sales, profit, and orders.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly


## Key Analysis
1. Overall Sales & Profit Performance
2. Category & Product Performance
3. Order Status & Revenue Loss
4. Payment, Fulfilment & Geographic Performance
